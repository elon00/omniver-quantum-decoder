# External Verification Record

## Purpose

This document records evidence required before Omniver Quantum Decoder can be represented as independently production-certified or market-ready under the Universal Reality System (URS).

## Current status

**External certification: NOT YET ESTABLISHED.**

Repository tests can demonstrate software behavior under the tested conditions. They do not, by themselves, constitute an independent security audit, regulatory approval, market validation, or certification of production readiness.

## Required independent evidence

1. Independent cryptographic/security review covering ML-KEM-768, ML-DSA-65 integration, key handling, serialization, hybrid authorization, and failure behavior.
2. Reproducible external review of the Shor/Grover implementation and all production-facing claims.
3. Independent verification of deployed artifacts and public application behavior.
4. Operational evidence for the supported production distribution of the Anna Executa, including Linux/cloud-agent deployment where applicable.
5. Real-user and sustained-usage evidence before making market-readiness claims.
6. Human sign-off by an accountable owner after reviewing all evidence.

## URS rule

Until the evidence above is independently supplied and reviewed, the correct classifications remain `REAL_VERIFIED` for tested software behavior, `EXPERIMENTAL` for research integrations, and `NOT CERTIFIED` for independent production/market readiness.
